Quick User Guide

1. Quick GitHub PR Review

  1. Click GitHub PR Review from the sidebar.
  2. Paste a PR link like https://github.com/owner/repo/pull/123.
  3. Click Parse.
  4. Select checklist items and expected outputs.
  5. Click Start Review.

The request is sent to chat and progress is streamed while the review runs.

2. Quick Confluence Page Review

  1. Click Confluence Page Review from the sidebar.
  2. Paste a Confluence page URL or page ID.
  3. Click Parse.
  4. Select checklist items and expected outputs.
  5. Click Start Review.

3. Using Your Own Instructions

No file upload yet. Options:

  • Paste key instructions into chat before starting review.
  • Keep a reusable prompt template locally.
  • Paste Confluence link first, then PR/page link.

4. Quick Tips

  • Clicking outside a panel closes it.
  • Use Ctrl+Enter in chat to send quickly.
  • Check URL format if parsing fails.
