Edit Confluence Credentials

Confluence Guide

  • Confluence Email: Your Atlassian account email.
  • Confluence API Token: Create at id.atlassian.com under Security > API tokens.
  • Confluence Base URL: Usually like https://company.atlassian.net/wiki.

Edit GitHub Credentials

GitHub Guide

  • GitHub Owner: Org/user that owns the repository.
  • GitHub Token: Create in Settings > Developer settings > Personal access tokens.
  • GitHub API Base URL: Keep https://api.github.com for github.com.

Quick User Guide

MunnAI helps you run guided code and content reviews with structured outputs, inline comments, and summary insights.

GitHub PR Review

  • Parse GitHub PR links and inspect changed files.
  • Run checklist-based review rules in one flow.
  • Produce inline comments, file-level notes, and summary feedback.

Confluence Review

  • Review pages by URL or page ID.
  • Detect grammar, readability, and structure issues.
  • Post inline and footer comments with optional rewrite suggestions.

Account Setup

  • Store GitHub owner/token and Confluence email/token.
  • Use show/hide controls for token fields while editing.
  • Send credentials as runtime auth for each request.

Live Progress

  • See real-time review steps in the chat stream.
  • Auto-fallback to direct requests if streaming is unavailable.
  • Track final status in the request hint area.

Fast Workflow

  1. Configure credentials in Account Setup.
  2. Choose GitHub PR Review or Confluence Page Review.
  3. Parse the link, pick checklist items, and start the review.
  4. Watch live progress and copy outcomes from chat.
