Recommended Workflow

  1. Open Account Setup and fill GitHub owner/token plus Confluence email/token.
  2. Choose GitHub PR Review or Confluence Page Review from the sidebar.
  3. Paste the PR or page link, then click Parse to validate input.
  4. Select checklist rules and expected outputs, or paste custom instructions in chat.
  5. Start review and monitor streamed progress in chat.
  6. Inline comments and a footer summary are posted automatically to the PR or page.

Applying Custom Instructions to a PR

Paste your own checklist or rules in chat before starting a review. MunnAI reads them and extends the standard checklist automatically.

Example: "Use this checklist for my next review: validate naming consistency, flag long lines, report security patterns. Expected output: inline comments + summary with top risks."

What Gets Checked Automatically

  • Naming conventions: PascalCase classes, camelCase JS/TS, snake_case Python
  • Consistent formatting and indentation across changed files
  • Cross-file consistency (naming, patterns, behavior alignment)
  • Security risks: hardcoded secrets, missing validation, SQL/XSS
  • Code quality: DRY violations, unused variables, complex functions
  • Documentation: missing docstrings, inaccurate comments

Prompt Template

Use this checklist for my next review:
- Validate naming consistency
- Flag long lines and unclear comments
- Report security-sensitive patterns
- Check cross-file naming alignment
Expected output:
- Inline comments for exact lines
- One summary comment with top risks

Inline Comment Format

Issue: Function name uses PascalCase
Rule: JS/TS functions must use camelCase
Fix: Rename getUser() to getUser (already correct)
     rename CreateUser() to createUser()

Fast Tips

  • Use Ctrl+Enter to send chat messages quickly.
  • Paste custom rules in chat before starting a review.
  • Click outside a panel or modal to close it.
  • If parsing fails, verify the PR or page link format first.
