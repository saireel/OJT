Recommended Workflow

  1. Open Account Setup and fill GitHub owner/token plus Confluence email/token.
  2. Choose GitHub PR Review or Confluence Page Review from the sidebar.
  3. Paste link or page ID, then click Parse to validate input.
  4. Select checklist rules and expected outputs.
  5. Start review and monitor streamed progress in chat.

Custom Instructions

For now, include your own rules directly in chat before launching a review.

Tip: Keep your reusable checklist prompt in a local note, then paste it when needed.
