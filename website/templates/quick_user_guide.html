Quick User Guide

How to run quick reviews and apply your own instruction checklist.

1) Quick GitHub PR Review

  1. Click GitHub PR Review from the sidebar.
  2. Paste a PR link like https://github.com/owner/repo/pull/123.
  3. Click Parse.
  4. Select checklist items and expected outputs.
  5. Click Start Review.

The request is sent to chat and progress is streamed while the review runs.

2) Quick Confluence Page Review

  1. Click Confluence Page Review from the sidebar.
  2. Paste a Confluence page link (full URL is okay) or page ID.
  3. Click Parse.
  4. Optional: select document type.
  5. Select checklist items and expected outputs.
  6. Click Start Review.

3) When You Have Your Own Instruction File

There is no direct file upload button yet. Use one of these options:

  1. Paste the key instructions from your file into chat before starting review.
  2. Keep a reusable local prompt template and paste it each time.
  3. If instructions are in Confluence, paste that link first, then your PR/page link.

Suggested instruction format:

Use this checklist for my next review:
- Validate naming conventions and consistency
- Flag long lines and unclear comments
- Report security-sensitive patterns
Expected output:
- Inline comments for exact lines
- One summary comment with top risks

4) Quick Notes

  • Clicking outside a review panel closes it.
  • Use Ctrl+Enter in chat to send quickly.
  • If parsing fails, check your URL format first.
